# Asterics-AAC-Helper

Helper tools for [Asterics AAC](https://github.com/asterics/Asterics-AAC).

These helper applications are provided:

- Speech: integration of external speech providers  - see folder  [interaction](https://github.com/asterics/Asterics-AAC-Helper/tree/main/speech)
- Interaction: connection with external devices (e.g. with COM/Serial ports) - see folder  [speech](https://github.com/asterics/Asterics-AAC-Helper/tree/main/interaction)
- Translation: adding translations or removing languages from Asterics AAC backup files (.grd) - see folder  [translation](https://github.com/asterics/Asterics-AAC-Helper/tree/main/translation)

For more information and instructions, please refer to the README files in the corresponding folders.
